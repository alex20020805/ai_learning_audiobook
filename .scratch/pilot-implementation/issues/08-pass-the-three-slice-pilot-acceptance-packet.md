# 08 — Pass the three-slice pilot acceptance packet

**What to build:** The learner can make a decision-ready judgment about the verbatim pilot using the accepted prose/hierarchy, mathematical notation, and code/visual selections from the reference Source Document. The evidence packet proves fidelity, usability, cost, traceability, and offline playback or identifies exact failures that must become regressions.

**Blocked by:** 07 — Deliver and inspect a complete offline Episode.

**Status:** ready-for-agent

- [ ] The frozen evaluation packet covers the three accepted reference selections, rendered-page gold evidence, atomic units, technical terms, pronunciations, valid Episode boundaries, and pinned runtime configurations.
- [ ] All three selections pass the established extraction, hierarchy, packing, verbatim script, visual handling, speech, duration, source-continuity, and Transformation Report gates without averaging away a critical failure.
- [ ] Text and speech comparisons use identical stage inputs, blinded labels, locked ratings, recorded versions and costs, and the accepted stage-specific routing rule.
- [ ] At least one full 15–25-minute Episode completes the endurance listen without skips, repeats, truncation, corrupt joins, or unacceptable listening effort.
- [ ] The learner confirms that the delivered M4A plays from iPhone Files without a network connection; the evidence distinguishes this manual check from delivery-copy status.
- [ ] Total and per-Episode cost remain within the approved ceilings or include explicit recorded overrides.
- [ ] Every evaluation run retains metrics, reviewer notes, artifacts, provenance, trace manifests, and a reproducible pass/fail decision.
- [ ] Every distinct critical or major failure becomes a permanent HTTP-boundary or evaluation regression case before the pilot can pass.
- [ ] The final evidence confirms that named functions are documented and that run/function input-output tracing is complete, correlated, bounded for large values, and free of credentials.
